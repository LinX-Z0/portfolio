Mega Man Maker

Three stages built with the same process, each with a different goal: mobility, easy combat, and puzzle.

Category
Level Design
  • Shared process · give every move a letter code, write each challenge as a combination of codes before building, then score how intense each zone is.
  • JumpMan · mobility and timing. Double jump and slide, asked more precisely as the stage goes on.
  • FIVENITE · easy combat. Pick your own weapon; rooms mix in breaking and building so fights are not just stand-and-shoot.
  • Prison Break · normal-difficulty puzzle. Rooms ask you to use several tools together, and hidden purple keys let you skip the hardest room.

These three stages are not separate one-offs. I used the same process on all of them: set a clear goal for the stage, describe every challenge using letter codes for the moves it needs, and only build what that description calls for. If I could not describe a room that way, it did not make it into the stage.

Each stage has its own page with the full level document, the move codes, and the intensity scores.
