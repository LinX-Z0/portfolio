Prison Break

Mega Man Maker. Normal puzzle stage. Juggle several tools in one room.

Role
Solo level design
Tool
Mega Man Maker
Theme
Puzzle + juggling
Scope
16 challenges, 8 pages
Set
4KOMA · FIVENITE

Where 4KOMA is difficulty over complexity, this map is allowed to be busy. Primary theme is puzzle rooms. Secondary is juggling: the room is the test of whether you can hold several tools at once. Normal means more mechanics, not meaner spikes.

Design intent

Checkpoints and safe spots sit under the parkour so a missed dash is a retry, not a run killer. The complexity budget goes into how many verbs a room asks for, not into how far a fail drops you. That is how “normal” and “busy” can coexist without becoming cruel.

I teach in layers: roll, then card throw for a key, then vertical throws, then throw-while-jumping, then midair dash alone before combining dash with jump, water, and one-block gaps. The ice gun is a late language shift — same weapon, three grades (walk on frozen fire, diagonal to wake a platform, spread to hit several targets) after dash and throw are already in muscle memory.

Purple keys look useless. If you picked them up, you skip the last room (the hardest). That is guided freedom: the gauntlet is still the intended path, but attention is a real alternate win, not a collectathon the game yells about. The skip only works if the keys never announce themselves as the skip. They have to look like dead loot until the door that accepts them.

The curve

OpenJust roll1
First puzzleB+C+D — throw, door, break3

Intensity climbs from 1 through 3–4 combination rooms, then 5–6 on dash and water, with ice sitting around 4–5 so the new language is readable. The last room is 7 on purpose. A few 3s and 4s sit between spikes so it is not a straight staircase. The skip exists so the peak is optional if you were paying attention — the curve still has a designed exam for everyone else.

Ice arrives late on purpose. Introducing a three-grade weapon before dash and throw are settled would turn every room into a reading test. After those verbs are muscle memory, ice can be a language shift instead of a pile-on.
