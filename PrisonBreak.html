Prison Break

Mega Man Maker. Normal puzzle stage. Juggle several tools in one room.

Intent

Where 4KOMA is difficulty over complexity (two verbs, stricter), this map is allowed to be busy. Primary theme is puzzle rooms. Secondary is juggling: the room is the test of whether you can hold several tools at once. Normal means more mechanics, not meaner spikes. Checkpoints and safe spots sit under the parkour so a missed dash is a retry, not a run killer.

I teach in layers: roll, then card throw for a key, then vertical throws, then throw-while-jumping, then midair dash alone before combining dash with jump, water, and one-block gaps. The ice gun is a late language shift — same weapon, three grades (walk on frozen fire, diagonal to wake a platform, spread to hit several targets) after dash and throw are already in muscle memory.

Purple keys look useless. If you picked them up, you skip the last room (the hardest). That is guided freedom: the gauntlet is still the intended path, but attention is a real alternate win, not a collectathon the game yells about.

Cadence

Sixteen challenges across eight pages. Combinations are the point, so the notation is written as stacks:

  • A roll
  • B card throw / B' vertical throw
  • C keyed door
  • D break block
  • E jump / E' jump in water
  • F midair dash / F' one-block dash
  • G ice / G' diagonal ice / G'' ice spread

First real puzzle is B+C+D. Dash-while-jumping is E+F. Ice is G, then G', then G'' as a three-step weapon tutorial. F' is the precision-dash exam before ice. Full table is in the PDF.

Pacing

Intensity climbs from 1 (just roll) through 3–4 combination rooms, then 5–6 on dash and water, with ice sitting around 4–5 so the new language is readable. The last room is 7 on purpose (midair dashes). A few 3s and 4s sit between spikes so it is not a straight staircase. The skip exists so the peak is optional if you were paying attention — the curve still has a designed exam for everyone else.

Role
