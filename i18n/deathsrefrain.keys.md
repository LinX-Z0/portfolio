# Death's Refrain i18n keys

Prefix: `dr.` — maps to `DeathsRefrain.html` case study.

## Meta / trailer
- `dr.meta.title` — document title
- `dr.trailerOpen` — Google Drive trailer link
- `dr.trailerTitle` — iframe title

## Cover
- `dr.lead` — lead under h1
- `dr.meta.*.dt` / `dr.meta.*.dd` — project-meta Role, Team, Pair, Courses, Timeline, Stack
- `dr.scan.*` — scan-strip five bullets (html)
- `dr.p.loop` / `dr.p.pair` / `dr.p.scope` — intro paragraphs after scan-strip
- `dr.cap.hero` — hero figcaption

## Design intent
- `dr.h.intent` — h3
- `dr.intent.p1`–`p3` — body paragraphs

## AP budget
- `dr.h.ap` — h3
- `dr.ap.intro` / `dr.ap.bridge` — intro + bridge before example turns
- `dr.ap.th.*` / `dr.ap.row.*` — cost table headers and cells
- `dr.ap.th.turn|spend|buys` / `dr.ap.ex.*` — example-turn table
- `dr.ap.p.*` — weapons, shield, damage, pickups paragraphs
- `dr.cap.los` — LoS figcaption

## Enemies
- `dr.h.enemies` — h3
- `dr.enemies.intro` / `dr.enemies.p.*` — intro + slime / souls / roster / lich
- `dr.enemies.th.*` / `dr.enemies.{scorpion,tome,slime}.*` — enemy table
- `dr.cap.lichBeam` / `dr.cap.lichSmash` — boss figcaptions

## Run
- `dr.h.run` — h3
- `dr.run.intro` / `dr.run.p.*` — flow + reward + objectives
- `dr.run.diagram.*` — SVG title, desc, labels, footer
- `dr.cap.run` — diagram figcaption

## Teaching / Lua / Playtests / Outcome
- `dr.h.teach` / `dr.teach.p*` — Teaching it
- `dr.cap.move` — move-range figcaption
- `dr.h.lua` / `dr.lua.p*` — Lua and integration
- `dr.cap.reward` — reward-screen figcaption
- `dr.h.playtests` / `dr.play.*` — playtests + tuning list
- `dr.h.outcome` / `dr.outcome.p*` — outcome and reflection

## Role / case-exit
- `dr.role.h` / `dr.role.li1`–`li5` — role heading and bullets
- `dr.exit.engineLabel` — Engine label alone
- `dr.exit.engine` — full case-exit Engine line (html)
