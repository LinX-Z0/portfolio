Hellmaker

Custom C++ engine for Death's Refrain — Team Infernumb, Year 2. Debugger and editor ImGui.

Hellmaker is the in-house engine under Death's Refrain. Three binaries share it: Engine (static library), Editor (ImGui tool), Sandbox (the game). Technical lead / engine champion is Loh Boon Cheong, Timothy. I was Design Lead on the game, and on the engine I wrote the global debugger plus the editor GUI layer that made that design job iterable.

Debugger

global_debugger is mine (engine-side, 100%). Log levels run trace through critical, plus off. Sinks are console, file, or both. A ring buffer keeps the last N messages. Init/terminate and crash helpers take a custom reason. It sits on spdlog and is linked by Engine, Editor, and Sandbox, so a gameplay fault and an editor fault hit the same pipeline.

The editor's DebugConsole is also mine: an ImGui window that pulls those logs live so you can filter what the engine is doing without attaching a second logger.

ImGui editor

manager_editorguirender is mine. It wraps Dear ImGui so the rest of the editor can draw windows without leaking ImGui types everywhere, then drives layout (docking, FPS, editor-mode toggle, jump back to the project launcher).

The asset browser is mine. I wrote the system; Timothy co-authored a smaller share (file picking through ImGuiFileDialog). Game view is a three-way file: Alfred and Timothy on render/gizmos, I contributed the remaining slice so the view could talk to the GUI manager. That split is why placing a tile was an editor click, not a C++ rebuild.

Why the tools existed

Death's Refrain is data on this runtime: GameObjects with transform, sprite, collider; Lua state machines (onEnter / onUpdate / onExit); YAML scenes and grid maps. I was authoring rooms against that contract. If logs were only in a terminal, and assets were only on disk, the design lead job stalls. Debugger plus console plus asset browser were how I kept mechanics and spaces aligned with what Hellmaker could actually run.

Team stack

C++20, CMake (Debug / Release / Shipment). GLFW windowing. FMOD audio. Lua on logic components. YAML maps. Dear ImGui in the editor, with gizmos and file dialogs. Render, physics, and the rest of the engine systems were owned by the champions below. This page is the tooling I shipped into that stack, not a claim on the renderer.
